# imov.dev

[imov.dev](https://imov.dev/) is a unified creative AI platform for generating videos, images, and music.

## Features

- Text-to-image and image-to-image generation
- Text-to-video and image-to-video creation
- AI music generation
- Pay-as-you-go credit packs with no monthly commitment
